1. METHODLOGY NORMALIZATION (CRITICAL FIX)
------------------------------------------------

The dashboard still groups methodologies using the raw text column from carbon_projects.

This is visible because entries like:

ACM0002
ACM0002 Grid-connected electricity generation from renewable sources

appear separately.

This means analytics are still grouping on:

carbon_projects.methodology

instead of using the normalized reference layer.

Implement the full normalization pipeline.

1. Create the junction table:

project_methodology_codes
- id
- project_id
- methodology_code
- raw_segment
- is_primary

2. During every project sync:

Split carbon_projects.methodology on ";" or ",".

Extract methodology codes using regex patterns such as:

ACM\d{4}
AM\d{4}
AMS-[IVX]+\.[A-Z]+\.\d*
VM\d{4}
VMR\d{4}
TPDDTEC
GS-MECD

3. Insert the extracted code into project_methodology_codes.

4. Link codes to ref_methodologies.

If a code does not exist yet:
create a provisional entry in ref_methodologies.

5. Update ALL analytics queries to use:

carbon_projects
JOIN project_methodology_codes
JOIN ref_methodologies

instead of grouping by carbon_projects.methodology.

6. Keep the original text field for display purposes.

Expected result:

ACM0002 appears only once in analytics.
