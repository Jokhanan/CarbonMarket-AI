PART 1 — ER SHEET MUST REFLECT REAL METHODOLOGY FORMULAS
--------------------------------------------------

Current issue:
The ER Excel export is still too simplified.

It is not enough to show:
- Gross ER = Baseline ER - Project ER
- Net ER = Gross ER - Leakage

I need the workbook to reflect the actual methodology logic.

The principle is:

Every calculated number in the ER sheet must come from either:
1. a methodology equation
2. a user-entered parameter
3. a clearly referenced derived value

There should be NO unexplained hardcoded calculated values.

For example:
If BE = A × B × C × D
then the Excel sheet must show:
- A in its own source/input cell
- B in its own source/input cell
- C in its own source/input cell
- D in its own source/input cell
- the BE result cell must contain the actual Excel formula referencing those cells

If one intermediate result is 15 because 3 × 5,
the ER sheet must show the 3 cell and the 5 cell,
and the 15 cell must be a formula, not a static value.
