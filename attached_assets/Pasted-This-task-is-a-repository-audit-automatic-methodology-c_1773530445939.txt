This task is a repository audit + automatic methodology classification + pack preparation.

The objective is to analyse the existing document repository and determine whether we already have enough documents to automatically build methodology packs (TPDDTEC, VM0050, etc.) without requiring manual uploads.

Do NOT redesign the architecture. The Methodology Pack Manager already exists.

Your task is to analyse the repository and build an automatic classification layer that can feed the existing pack system.

--------------------------------

PART 1 — REPOSITORY AUDIT

First inspect the existing repository.

Look at the documents table and document_chunks table.

Determine:

• how many documents exist in total
• how many documents have extracted text
• how many documents appear to be:
  - PDD
  - Monitoring Report
  - Validation Report
  - Verification Report
  - Methodology document
  - Tools / guidance

Produce counts for each category.

ACM0002
AMS-I.D

"VM"

3) detect references inside the text body.

Extract:

methodology_code
registry
document_type
project_name (if possible)
