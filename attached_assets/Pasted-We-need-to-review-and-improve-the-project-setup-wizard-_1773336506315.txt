1. PROJECT TYPE LOGIC (Cookstoves vs MECD)

Currently the wizard asks:

Activity type:
- Cookstoves / Thermal energy
- Metered & Measured Cooking Device (MECD)

This is confusing.

From a user perspective, a developer usually knows:
- baseline fuel
- project fuel

They often do NOT know the methodology name yet.

A better workflow may be:

Step 1
Select project category:
- Cooking devices
- Renewable electricity
- Other

Step 2 (if cooking devices selected)
Select baseline fuel:
- wood
- charcoal

Step 3
Select project fuel:
- wood
- charcoal
- LPG
- electricity
- biogas
- bioethanol
- other

Then the system automatically determines the methodology:

Example:

baseline = wood
project = wood
→ TPDDTEC

baseline = wood
project = LPG
→ Metered & Measured Cooking Devices

baseline = wood
project = electricity
→ Metered & Measured Cooking Devices

If standard = Verra
→ VM0050

Question:
Is this automatic methodology detection approach better than the current two-branch approach?

If yes, propose the revised decision tree.
