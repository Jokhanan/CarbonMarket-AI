STEP 1 — Methodology Normalization

Currently methodology values are stored as raw strings.

Example problems:

ACM0002
ACM0002 Grid-connected
ACM0002 - grid electricity

TPDDTEC v4.0
TPDDTEC v3.1

These appear as separate rows in analytics.

Design a normalization approach.

Create a methodology library table:

methodology_library
- methodology_code
- methodology_family
- registry
- sector
- technology

Examples:

ACM0002 → Grid Electricity
AMS-I.D → Grid Electricity
TPDDTEC → Clean Cooking
VM0006 → Clean Cooking

Explain how to extract the methodology code from raw registry strings.

-----------------------------------------

STEP 2 — Country Normalization

Country names currently come raw from each registry.

Examples:

Democratic Republic of Congo
Congo, Democratic Republic
DR Congo

Design a country normalization approach.

Introduce a countries table:

countries
- country_iso
- country_name
- region
- subregion

Then map raw values to normalized country_iso.
